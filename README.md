# Kahnaroc website
Website for my conlang Kahnaroc. It contains the dictionary, all of the grammar rules and the Kahnur keyboard. Additionally, there are scripts for fixing and modifying the dictionary entries. The dicionary entries can be found in [dictionary/words.json](dictionary/words.json). The structure is as follows: word, translation/meaning, word type. The website is hosted online at https://kahnaroc.neocities.org/. It is made with pure HTML/CSS/JS, uses no dependencies and as such can be hosted easily.

## About Kahnaroc
Kahnaroc is a conlang I decided to make after learning about a few of the popular conlangs. At first, I wrote all of the grammar rules and the dictionary on paper, but later on decided to make a website dedicated to it. It has unique punctuation and constant pronunciation, an alphabet subset, only 3 tenses and pronouns do not change verb suffixes (unlike German or Russian).

The biggest flaws of the language are that it doesn't have a large dictionary and that, just like English, a lot of the words have multiple meanings. If I was to make a new conlang from scratch, I'd make a single action or thing have a single word associated with it. In the end, it didn't turn out how I wanted it to but it was a great learning project and could serve as a stepping stone for a different conlang in the future.
